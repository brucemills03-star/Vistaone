# Vistaone

Vistaone is a modern IPTV player application designed to provide a simple, fast and premium streaming experience.

## Features

- Live TV
- Movies
- TV Series
- Favourites
- Search
- Electronic Programme Guide (EPG)
- Modern easy-to-use interface
- Support for IPTV playlists and Xtream Codes API

## Project

Vistaone is currently under development.

The goal is to create a clean and professional IPTV player that can run across multiple devices.

## Important

Vistaone is a media player only.

It does not provide, host or sell television channels, movies, streams or other media content.p
